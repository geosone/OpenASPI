# ASPIFDD.SYS

Planned ASPI removable-media driver for LS-120/240, ZIP, Clik!, and compatible
devices.  It is separate from ASPIDSK so media change, eject/lock, format, and
device quirks do not complicate the safe generic disk path.

Original drivers in the local DOS archive are compatibility fixtures only and
will not be redistributed with OpenASPI.
